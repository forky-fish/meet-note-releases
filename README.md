# Meet Note releases

Release builds for **Meet Note**, the LAN-first collaborative meeting notes app of
the Purple suite. The source code lives in a private repository.

- **Beta and pre-release builds** for every version line land here first
  (`1.0.0-beta.N` and later betas); stable versions follow only after a beta
  has been tested.
- **Unsigned.** Windows SmartScreen and macOS Gatekeeper will warn.
- Every release lists `SHA256SUMS` for its assets.
- Feedback and bug reports: open an issue in this repository.
